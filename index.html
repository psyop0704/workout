이 문서의 위치: 개인의 수행 기록·수면·회복 데이터가 아직 없는 상태에서 만든 문서이므로, "개인별 최적이 입증된 처방"이 아니라 실행 후 조정을 전제로 한 근거 기반 시작안입니다. 2~4주의 수행 지표(반복수·회복·통증)를 보고 다듬는 것까지가 이 루틴의 일부입니다.

⚙ RIR · 휴식 · 진행 규칙▾
  • RIR 정의 — 정상 자세로 추가 수행 가능한 예상 반복수. RIR 0은 정상 자세의 여유가 없는 상태이지, 실패 반복이나 강제 반복을 하라는 뜻이 아님
  • 벤치·스쿼트·RDL — 기본 RIR 2. 상태가 좋으면 마지막 세트만 RIR 1
  • 머신 프레스·로우·풀다운 — RIR 1~2
  • 고립운동 — 대부분 RIR 1~2. 안정적인 종목(레터럴·컬 등)의 마지막 세트만 선택적으로 RIR 0~1
  • 휴식 — 무거운 복합 2~3분(필요 시 연장) / 고립 90~120초에서 시작, 수행이 유지되면 단축 가능
  • 템포 — 내리는 동작은 통제, 올리는 동작은 의도적으로 힘 있게. 모든 반복을 초 단위로 강제하지 않음
  • 증량 조건 — 반복수 상단 도달 + 목표 RIR·가동범위·자세 유지. 사용 가능한 가장 작은 증량으로(마이크로 플레이트·반 핀 등). 특정 kg를 의무 규칙으로 두지 않음
  • 딜로드 — 고정 주기가 아니라 누적 피로와 수행 추세로 결정. 신호가 이어지면 1주간 세트 절반·중량 85~90%로 낮춤
부하 축소를 검토할 신호(2세션 이상 지속): 같은 조건에서 반복수 하락 · 과도한 피로감·수면 질 저하 · 의욕 급감. 통증은 별개입니다 — 단순 피로로 분류하지 말고 원인을 확인하고, 딜로드만으로 해결된다고 가정하지 마세요. 지속되면 진료가 우선입니다.
📈 증량 진행 · 당일 컨디션 조절 (v8.1 추가)▾

증량 진행 예시 — 반복수를 먼저 채우고, 조건이 충족되면 가능한 최소 단위로 올립니다. 덤벨프레스 3세트(한 손 기준) 예시:

진행중량세트별 기록다음 세션
첫 기록20kg10 / 9 / 8회같은 중량 유지
이후20kg11 / 10 / 9회같은 중량 유지
조건 충족20kg12 / 12 / 12회 · RIR 1~2 · 자세 유지최소 단위 증량
증량 후다음 덤벨8~10회 수준다시 반복수 쌓기

반동이 커지거나 가동범위가 줄어 늘어난 횟수는 같은 조건의 발전으로 기록하지 않습니다. 매주 이 속도를 의무로 두지 않습니다.

당일 컨디션 조절 — 목표 RIR을 기준점으로 그날 상태에 맞춥니다:

당일 상태조절
평소보다 가볍게 느껴짐목표 범위 안에서 반복 추가. 증량 조건을 충족했다면 소폭 증량
보통기존 중량으로 목표 RIR 유지
워밍업부터 무겁고 반복이 떨어짐중량을 약 5~10% 낮춰 목표 RIR에 맞춤 (실무적 조절 예시 — 1RM 측정·계산 아님)
피로 누적 + 여러 종목 수행 하락 지속일시적으로 세트 수를 줄이고 회복 상태 점검
특정 동작에서 관절 통증해당 동작 중단 후 원인 확인 — 중량만 낮춰 밀어붙이지 않기
종목 유지 원칙: 주력 종목은 6~8주 정도 같은 구성으로 유지하며 기록을 비교합니다. 잦은 무작위 교체는 진행 판정을 어렵게 만듭니다. 교체는 통증·기구 사정·지속적 정체가 있을 때 검토하면 되고, 잘 진행되면 더 오래 유지해도 됩니다.
📊 주간 세트 감사 (v8)▾

집계 기준: 직접 = 해당 근육이 주동으로 일하는 작업세트 / 간접 = 보조로 참여하는 세트. 간접 세트를 ×0.5로 환산하는 방식은 계획용 추정이며 실측이 아닙니다. 특정 범위(예: 10~20세트) 충족 여부보다 직접·간접 자극과 개인의 진행·회복을 함께 평가하세요.
