# 주간 운동 루틴 v8 · 동작 해부도

## 이번 수정
- 운동을 누르면 회색 인체와 붉은 근육 강조가 있는 동작 그림을 크게 표시합니다.
- 기본은 두 자세 나란히 보기이며, `동작 재생`으로 애니메이션을 볼 수 있습니다.
- 턱걸이/랫풀다운, 플랭크/데드버그 등은 그림 위의 버튼으로 선택합니다.
- 정지 자세가 중심인 스트레칭·플랭크는 한 자세로 표시합니다.
- 웨이트 32개를 포함해 기존 39개 항목 전체에 동작 이미지를 연결했습니다.
- 기존 루틴의 운동 순서·세트·자세 설명은 보존했습니다.
- 기존 간단 근육도는 `근육 위치 간단히 보기`를 펼치면 확인할 수 있습니다.

## 실행
압축을 풀고 `pwa_v8/index.html`을 열면 PC에서 바로 사용할 수 있습니다.
`index.html`만 따로 옮기지 말고 폴더 전체를 함께 보관하세요.

기존에 사용하던 웹 호스팅 주소가 있다면 이 폴더의 파일과 `assets` 폴더를 모두 교체하세요.
아이폰에서는 HTTPS 주소를 Safari로 열어 공유 메뉴의 `홈 화면에 추가`로 설치합니다.
첫 접속 때 전체 이미지 저장이 끝난 후 오프라인 사용이 가능합니다. 브라우저가 저장 공간을 비우면 다시 온라인 접속이 필요합니다.
